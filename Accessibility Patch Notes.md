# Accessibility Patch Notes

## Community feedback on the study group:
- Live study group sessions are recorded on YouTube, so that participants from other time zones can take part as well.
- Knowledge Check question format was unclear, so session 2 included a segment on how to answer them. If requested, we will repeat this segment in the last session too.
- Subtitles move quickly during live sessions, therefore the blog post summaries now also include a video with open captions instead of an embedded YouTube link.
- Test ID testing processes can build on previous test IDs, which can become hard to follow on slides alone. For the live sessions, participants get a "cheat sheet" handout with the testing steps and evaluation questions to follow along.

## Trusted Tester course and exam
If you need help accessing the content on the CX Training portal, you can reach out to the [DHS Accessibility Helpdesk](https://forms.office.com/pages/responsepage.aspx?id=bOfNPG2UEkq7evydCEI1SnfrzEzK4yBHicd5JircsOBUNjFHVlpZUkFIMlU2Uk5FUjM0RFk1OTc4TS4u&route=shorturl). While the course content is presented in a Section 508 compliant way, some of the test IDs require visual checks or comparing written and audio info. Because of this, students with disabilities have trouble completing the Trusted Tester certification. If you have suggestions for workarounds, please share them with the community!

### Barriers for Deaf and Hard of hearing students
Deaf and Hard of hearing students may encounter trouble with these test IDs, as they rely on checking for and verifying audio content. If you have suggestions for work arounds, please share them with the study group community.

#### Topic 16 Pre-Recorded Audio-Only, Video-Only, and Animations
- Test ID 16.A Audio-Only: requires transcripts are provided for pre-recorded audio-only content. Transcripts must be accurate and complete, including relevant sounds in addition to dialogue such as doors banging, sirens wailing, identification of speakers in dialogue, etc. Images of text are not acceptable as transcripts.
- Test ID 16.B Video-Only: requires that text or audio alternatives are provided for pre-recorded video-only content. The alternatives must include the same information that the video-only presentation displays (e.g., if the video includes multiple characters, the alternative must identify which character is associated with each depicted action). Images of text are not acceptable as text alternatives.

#### Topic 17 Synchronized Media
- Test ID 17.A Captions: requires that accurate captions are provided for pre-recorded synchronized media. Captions must be time-synchronized and equivalent, and include all non-dialogue audio information needed to understand the program content, including sound effects, music, laughter, speaker identification and location. The captions must also not obscure relevant video content.
- Test ID 17.B Audio Description: requires that, for pre-recorded synchronized media, the main soundtrack combined with audio descriptions adequately describe important visual details. This includes actions, characters, scene changes, onscreen text, etc. Transcripts and non-synchronized alternatives alone will not meet this requirement.
- Test ID 17.C Captions (live): requires accurate captions for live synchronized media. The captions must be time-synchronized and equivalent. Minor discrepancies in captions for live broadcasts may be acceptable due to limitations of real-time caption capabilities.

### Barriers for blind students
Blind students who mostly rely on a screen reader may encounter trouble checking for the following test IDs. If you know of work arounds, please share them with the community. 

#### Topic 5 Forms
- Test ID 5.A Forms label provided: requires that all form fields have visual labels or instructions. This test only checks for the presence of visual labels; the accuracy of those labels is tested in Test ID 5.B. If possible, any disabled form fields should be enabled for testing. This applies to all Test IDs in this topic.
- Test ID 5.B Forms descriptive label: requires that the visual labels of instructions of form fields are sufficiently descriptive. This includes information about required fields or data formats.
